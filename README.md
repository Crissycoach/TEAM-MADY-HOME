# TEAM MARKETING AUTONOMO — MADY HOME TRENTO

Repository operativo del team virtuale di marketing per **Mady Home Trento**.

Obiettivo: aumentare occupazione, prenotazioni e profitto usando prioritariamente
canali gratuiti/organici, nel periodo **18 settembre 2026 → 31 ottobre 2026**.

Budget marketing di partenza: **0 €**.


## Legenda usata in tutti i documenti

- **FATTO** → informazione verificata online con fonte
- **IPOTESI** → deduzione ragionevole, da validare
- **TEST CONSIGLIATO** → esperimento da lanciare per validare un'ipotesi
- **DATO INTERNO NECESSARIO** → informazione che solo il proprietario di Mady Home può fornire

approvazione, come richiesto. Le richieste di dati interni indispensabili sono
